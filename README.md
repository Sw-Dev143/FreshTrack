# FreshTrack 

**FreshTrack** is a smart assistant designed to help you track expiration dates of your products and manage your medication reminders, ensuring zero waste and a healthier lifestyle.

## 🚀 Features

- **Barcode Scanner**: Quickly add products using the built-in barcode reader (Open Food Facts integration).
- **Smart Notifications**: Receive alerts 7 days, 3 days, and on the day of expiration.
- **Medication Reminders**: Track your medications with custom dose times and logs.
- **Shopping List**: Automatically generate shopping lists from expiring products.
- **Global Localization**: Support for 7 languages (English, Turkish, German, Spanish, French, Japanese, Chinese).
- **Theme Support**: Modern UI with Light and Dark mode.
- **Data Security**: Local backup and restore functionality.

## 🛠 Tech Stack

- **Framework**: React Native (Expo)
- **State Management**: React Context API
- **Storage**: AsyncStorage
- **Localization**: i18next & react-i18next
- **Notifications**: expo-notifications
- **Styling**: Vanilla CSS (StyleSheet)

## 📦 Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Sw-Dev143/FreshTrack.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the project:
   ```bash
   npx expo start
   ```
